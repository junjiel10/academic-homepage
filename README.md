# 个人学术主页 — 高等教育评估与质量保障

一个**纯静态、中英双语、数据驱动**的个人学术主页，用于分享高等教育评估与质量保障体系相关知识。无需构建工具、无需数据库，直接用浏览器打开即可运行，也可免费托管到 GitHub Pages / Vercel / Netlify 或院校服务器。

## 功能特性

- 🌏 **中英双语一键切换**（选择保存在本地，自动记忆）
- 📱 **响应式设计**：桌面 / 平板 / 手机自适应，移动端抽屉式导航
- 🧭 六大板块：首页 / 个人简介 / 研究领域 / 学术成果 / 知识分享 / 联系方式
- 📖 内置 4 篇示例文章（质量保障体系、OBE 学习成果评估、院校评估与专业认证、质量文化），点击卡片即可全屏阅读
- 🎨 学术深蓝 + 金配色，滚动显现动画

## 目录结构

```
学术主页/
├── index.html        # 页面外壳（导航 + 容器）
├── css/style.css     # 全部样式
├── js/
│   ├── data.js       # ★ 所有内容（姓名/简介/成果/文章），改这里即可
│   └── app.js        # 渲染引擎（一般无需改动）
└── README.md
```

## 如何自定义内容

**只需编辑 `js/data.js`**，保存后刷新页面即可生效：

| 想改什么 | 改哪里 |
| --- | --- |
| 姓名、邮箱、头像图标 | `PROFILE` |
| 首页横幅、标签、动态 | `HOME` |
| 个人简介、教育背景、导师寄语 | `ABOUT` |
| 研究领域与关键词 | `RESEARCH` |
| 论文 / 会议 / 项目 | `PUBLICATIONS` |
| 知识专栏文章 | `KNOWLEDGE.articles` |
| 联系方式 | `CONTACT` |

> 每条内容都提供 `zh` / `en` 两套文案。某项留空时会自动回退到另一语言，可逐步补充英文版。
> 文章正文用 HTML 书写（支持标题、列表、引用、表格），详见 `data.js` 中 `KNOWLEDGE.articles[].body`。

### 常用替换点

1. `PROFILE.email` → 替换为真实邮箱
2. `PROFILE.name` → 替换为真实姓名
3. 头像目前是默认图标，可在 `index.html` 或 CSS `.avatar` 处换成照片
4. 页脚版权年份与文案在 `index.html`

## 本地预览方式

方式一（最简单）：直接双击打开 `index.html`。

方式二（推荐，保持路径正常）：在 VS Code 中安装 **Live Server** 扩展并点击 “Go Live”，或运行：

```bash
# 任意静态服务器均可
npx serve .
```

## 部署建议

- **GitHub Pages**：把本目录推送到仓库，Settings → Pages → 选分支 `main` 根目录即可。
- **Vercel / Netlify**：拖入本目录即可，无需配置。
